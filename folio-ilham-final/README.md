
# Ilham Sandi — Folio-lite (Next.js + GSAP + Tailwind)

Portofolio animatif sederhana terinspirasi dari Folio.
Siap deploy di Vercel.

## Jalankan Lokal
```bash
npm install
npm run dev
```
Buka http://localhost:3000

## Deploy ke Vercel
- Buat repo GitHub baru, upload semua file ini.
- Masuk ke vercel.com → New Project → Import repo → Deploy.

## Edit Konten
- Ganti gambar di `/public/images` dengan render kamu.
- Ubah link sosmed di `components/Contact.tsx`.
- Ubah teks di `components/About.tsx` bila perlu.
